# Coreward

轻量 Linux CPU 核监视工具，用于发现其他用户的进程或线程是否出现在你关注的核上。

## 功能

- 指定一个或多个 CPU 核，支持 `3`、`0-7`、`0-3,8,10` 等写法。
- 默认每秒扫描所有线程，也可选择只检查每个进程的主线程。
- 默认过滤自己，支持自定义排除用户或查看所有用户。
- 按采样 CPU 使用率过滤低负载活动，默认阈值为单核 1%。
- 支持极低优先级模式，优先选择较空闲的核运行。
- 在终端提示活动记录，对重复记录限流，并支持定时退出。

## 快速开始

需要 Linux 和 Python 3.6+，无需安装第三方 Python 库。

```bash
./coreward.py 0-7
```

默认每秒检查一次，排除当前用户，按 `Ctrl+C` 退出。也可以用 `python3 coreward.py 0-7` 启动。

`core.sh` 是早期原型，仅供参考；请使用 `coreward.py`。

## 常用用法

```bash
# 降低监视器的调度优先级
./coreward.py 0-7 -l

# 排除指定用户，替换默认过滤列表；空字符串表示不过滤用户
./coreward.py 0-7 -x alice,bob
./coreward.py 0-7 -x ''

# 只提示 CPU 使用率达到单核 5% 的活动
./coreward.py 0-7 -t 5

# 只检查每个进程的主线程，可能漏掉工作线程的活动
./coreward.py 0-7 -s process
```

## 选项

| 短选项 | 长选项 | 说明 | 默认值 |
| --- | --- | --- | --- |
| `-i` | `--interval` | 刷新间隔，秒 | `1` |
| `-s` | `--scope` | `thread` 扫描所有线程；`process` 只检查主线程 | `thread` |
| `-x` | `--exclude-users` | 排除用户名或 UID，逗号分隔；`''` 表示不过滤用户 | 当前用户 |
| `-l` | `--low-priority` | 极低优先级，优先选择较空闲的核 | 关闭 |
| `-r` | `--repeat` | 同一线程、用户和核的重复提示间隔，秒 | `5` |
| `-t` | `--threshold` | 最低采样 CPU 使用率，单核百分比；`0` 关闭过滤，范围 0–100 | `1` |
| `-d` | `--duration` | 运行时长，秒；不指定则持续运行 | — |
| `-h` | `--help` | 显示帮助 | — |

## 输出示例

```text
2026-01-01 12:00:00 user="alice" uid=1000 pid=1234 tid=1235 last_cpu=6 state=R delta_ticks=5 cpu_pct=5.25 comm="worker"
```

`PID` 是进程编号，`TID` 是线程编号，`last_cpu` 是最近运行核。`cpu_pct` 是该线程在采样期间的 CPU 使用率，100% 表示占满一个逻辑核。

## 使用须知

- 默认过滤当前用户；通过 sudo 启动时过滤调用 sudo 的用户。显式 `-x` 替换默认列表，监视器自身始终不报告。
- 进程模式只检查主线程。排查多线程程序时，建议保留默认线程模式。
- 正阈值下首次采样只建立基线。阈值按各线程分别判断，进程模式也不会汇总工作线程的负载。
- 最近运行核不代表全部运行时间都发生在该核上；轮询也可能漏掉两次采样之间的短暂活动。
- 系统权限和容器可见范围可能限制检测能力，没有提示不等于目标核完全无人使用。
- 极低优先级模式可以减少调度竞争，但系统繁忙时可能延迟刷新和退出响应。

## 资源开销

开销随扫描线程数和刷新频率增长。建议使用默认 1 秒间隔；可用 `-d 30` 短时运行并查看退出统计。
